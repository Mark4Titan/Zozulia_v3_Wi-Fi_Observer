# Zozulia v3

This project uses ESP-IDF with Arduino as a component and ESP-DSP.

## Build

Install ESP-IDF 5.1.1 or later and activate its environment, then run from the
project directory:

```sh
idf.py set-target esp32c6
idf.py build
idf.py -p PORT flash monitor
```

Replace `PORT` with the serial port for the ESP32-C6 board. The component
manager downloads Arduino and ESP-DSP based on `main/idf_component.yml`.

# ESP32-C6 Multi-Pattern Audio Analyzer & Hardware Hub

Автономний акустичний розвідувальний вузол та апаратний хаб на базі мікроконтролера **ESP32-C6**. Проєкт поєднує в собі багатоканальний спектральний аналіз звуку (FFT), захист від спаму, а також апаратне керування колекторним двигуном через ESC та живленням камери за допомогою PWM-реле. Управління та моніторинг здійснюються локально через веб-інтерфейс або дистанційно по протоколу **RS485**.

---

## 🚀 Основні Можливості

1. **Акустичний Аналіз (FFT):**
   - Оцифрування звуку через I2S мікрофон (`SPH0645` тощо) на частоті дискретизації 16 кГц.
   - 6 незалежнихconfigurable патернів для виявлення сигналів (голоси, FPV-дрони, кастомні частоти).
   - Апаратне прискорення FFT (`esp_dsp`).
   - Динамічне авторегулювання чутливості (**AGC**) з можливістю ручного калібрування лімітів.
   - Інтелектуальний захист від спаму (тимчасове «засинання» мікрофона при занадто частій активації тривог).

2. **Керування Колекторним Мотором (ESC 10A):**
   - Робота за стандартним протоколом RC-серво (`50Hz`).
   - Апаратне вимкнення силової лінії живлення ESC через оптопару (`PC817` тощо) для економії енергії та безпеки.
   - Автоматична ініціалізація та «ручний» розгін з мертвих зон (захист від пищання ротора).
   - Програмна пауза (`800 мс`) та автоматичний перехід через нейтраль при зміні напрямку руху (захист редуктора і запобігання збоїв реверсу).
   - Дискретне керування з 7 кнопками (`MAX R`, `MID R`, `MIN R`, `STOP`, `MIN F`, `MID F`, `MAX F`).

3. **Керування Камерою (PWM Реле):**
   - Миттєве вмикання/вимикання живлення камери через PWM-сигнал на реле (`1.0 мс` — вимкнено, `2.0 мс` — увімкнено).

4. **Двостороння комунікація (RS485 / UART):**
   - Неблокуюче асинхронне читання команд для збереження високої швидкодії аудіообробки.
   - Підтримка швидких текстових команд (`ESC:80`, `CAM:1`, `MUTE:0` тощо).
   - Повна підтримка JSON-пакетів для синхронізації налаштувань.
   - Автоматичний перехід у режим **Failsafe** (підняття власної точки доступу Wi-Fi з Captive Portal) при втраті зв'язку по RS485.

## 📌 Апаратна конфігурація (Пінінг ESP32-C6)

| Призначення | Пін ESP32-C6 | Опис |
| :--- | :--- | :--- |
| **I2S BCLK** | `GPIO_NUM_6` | Тактування мікрофона |
| **I2S WS** | `GPIO_NUM_7` | Вибір каналу Word Select |
| **I2S DIN** | `GPIO_NUM_4` | Дані мікрофона (Data In) |
| **RGB LED** | `GPIO_NUM_8` | Вбудований індикатор стану (NeoPixel) |
| **UART / RS485 TX** | `GPIO_NUM_16` | Передача даних RS485 |
| **UART / RS485 RX** | `GPIO_NUM_17` | Прийом даних RS485 |
| **RS485 DE/RE** | Опціонально (`-1` за замовчуванням) | Керування напрямком трансивера (для MAX485) |
| **ESC PWM** | `GPIO_NUM_2` | ШІМ-сигнал керування регулятором ходу |
| **ESC Switch (Оптопара)** | `GPIO_NUM_3` | Управління силовими ключами ESC |
| **Camera Relay PWM** | `GPIO_NUM_5` | ШІМ-керування реле живлення камери |

## 🌐 Інтерфейси Управління

### 1. Веб-інтерфейс (Wi-Fi Access Point)
Коли пристрій втрачає зв'язок по RS485 (або за відсутності ACK), він створює точку доступу:
* **SSID:** `Wi-Fi Observer`
* **Пароль:** `12345678`
* **IP-адреса:** `http://192.168.4.1` (включений DNS Captive Portal — перенаправляє автоматично).

У веб-інтерфейсі доступні:
* Візуалізація спектра FFT в реальному часі та VU-метр.
* Тонке налаштування 6 частотних патернів, порогів спрацювання та рівнів ескалації.
* Керування чутливістю (AGC / Ручний Gain).
* Кнопки дискретного керування мотором та реле камери.
* Сторінка експорту/імпорту повної конфігурації у форматі `.json` (`/config`).

### 2. Керування по RS485 (UART)
Основний модуль може надсилати текстові команди (закінчуються символом перенесення рядка `\n`):

* `ESC:100` — увімкнути двигун вперед на 100% (допустимі значення: `-100` ... `100`).
* `ESC:0` — зупинка мотора (нейтраль).
* `CAM:1` — увімкнути живлення камери.
* `CAM:0` — вимкнути живлення камери.
* `MUTE:1` — увімкнути загальний режим тиші (Master Mute).
* `STATUS` — запит поточного стану пристрою.
* `ACK` — пінґ-повідомлення для підтримки зв'язку та запобігання переходу в режим Failsafe.

При спрацюванні акустичної тривоги пристрій самостійно надсилає в шину RS485 повідомлення типу:
`ALARM:HUMAN_VOICE LVL:2`

## 🛠 Збірка та Прошивка

Проєкт розроблений для середовища **PlatformIO** або **Arduino IDE** з використанням ядра ESP32.

1. **Залежності (PlatformIO `platformio.ini`):**
   - `arduino` (ESP32 core v3.x)
   - `bblanchon/ArduinoJson @ ^7.x`
   - `links2048/WebSockets @ ^2.4.x`
2. Переконайтеся, що у вас підключені бібліотеки цифрової обробки сигналів (`esp_dsp`).
3. Завантажте код на плату ESP32-C6.
